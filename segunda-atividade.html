Segunda Atividade: Dominando Branches no Git

Aprenda a trabalhar em paralelo criando sua própria ramificação de desenvolvimento de forma segura e colaborativa.

O que é uma Branch?

Uma branch (ramificação) é como uma linha do tempo paralela no seu projeto. Ela permite que você crie novos arquivos e funcionalidades livremente, sem interferir no trabalho dos seus colegas e mantendo a versão principal (master) protegida e estável até que tudo esteja pronto.

branch: master
sua branch
↳
⚡

Assistente de Nomenclatura da sua Branch

Digite seu primeiro nome e sobrenome para gerar automaticamente os comandos customizados com o seu nome:

1

Sincronizar o Repositório Local

Antes de criar qualquer branch, você deve sempre garantir que está na branch principal (master) e baixar as últimas alterações enviadas pelo professor e colegas de turma.

git-bash / terminal
$ git checkout master
$ git pull
💡
Por que fazer isso? O git pull atualiza seu computador com o repositório do GitHub. Criar sua branch a partir de uma master atualizada evita conflitos de versão mais tarde!
2

Criar e Entrar na sua Nova Branch

Utilize o parâmetro -b para criar a branch e já alternar automaticamente para ela. O padrão de nome para esta aula é atividade2-seunome-seusobrenome.

Comando Personalizado
$ git checkout -b atividade2-seunome-seusobrenome
⚠️
Regra de Ouro da Nomenclatura: Use apenas letras minúsculas, sem espaços e sem acentos ou caracteres especiais. Separe as palavras com traço (-).
Exemplo: git checkout -b atividade2-felipe-carreiro
3

Criar seu Arquivo de Entrega

Abra o projeto no VS Code (ou explorador de arquivos) e localize a pasta Segunda Atividade/. Crie um arquivo de texto com o seu nome completo.

📂 Local da pasta: Segunda Atividade/
📄 Nome do arquivo: Seu Nome Completo.txt

Conteúdo do arquivo (copie e preencha):

Estrutura do Texto
Nome: [Seu Nome Completo] Jogo Favorito: [Nome do Jogo] Minha Branch: [Nome da sua branch]
4

Salvar e Fazer o Commit

Agora adicione o arquivo criado à área de preparação (staging area) e registre o seu commit com uma mensagem clara de identificação.

git-bash / terminal
$ git add .
$ git commit -m "Entrega Atividade 2 - [Seu Nome]"
📝
O que isso faz? O git add . prepara todos os arquivos modificados. O git commit cria um ponto na história da sua branch com a sua mensagem.
5

Enviar a Branch para o GitHub (Push)

Envie sua branch e seu commit para o repositório remoto no GitHub. Como é a primeira vez que você está enviando esta branch, usamos a flag -u origin.

Comando de Envio
$ git push -u origin atividade2-seunome-seusobrenome
🚀
O que significa -u origin? Estabelece uma conexão permanente (upstream tracking) entre a sua branch no computador e a nova branch criada no GitHub.

Checklist de Conclusão da Atividade

Clique nos passos conforme você for completando para acompanhar o seu progresso:

0 de 5 etapas concluídas 0%
Passo 1: Dei git checkout master e git pull para atualizar o repositório.
Passo 2: Criei minha branch com git checkout -b atividade2-meunome-meusobrenome.
Passo 3: Criei o arquivo Seu Nome Completo.txt dentro da pasta Segunda Atividade/ com as informações preenchidas.
Passo 4: Adicionei e commitei com git add . e git commit -m "...".
Passo 5: Enviei para o GitHub com git push -u origin sua-branch.

🔍 Como ter certeza de que deu tudo certo?

  • Digite git branch no terminal: a sua branch deve estar destacada em verde com um asterisco (*).
  • Digite git status: o terminal deve informar "nothing to commit, working tree clean".
  • Acesse a página do repositório no GitHub no navegador: abra o menu dropdown de branches (onde diz master) e confirme que a sua branch atividade2-... está listada lá! 🎉
